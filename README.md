## About the Project

Medsy is an online pharmacy design inspired by the Tata 1mg experience. It helps users find a medicine, compare generic alternatives, upload a prescription, check out, and track an order. The design has 13 screens:

Home, Search results, Medicine details, Compare alternatives, Upload prescription, Checkout, Track order, Monthly refill (Care Plan), Lab tests, Consult doctor, Ayurvedic, Health products and Health records.

## Usability Testing (Microsoft Clarity)

- The Figma design was built as a working website and published on GitHub Pages.
- Microsoft Clarity's tracking code was added to all pages to record user sessions, heatmaps and dashboard insights.
- The data collected was small (a few sessions and page views), so the results show how the tool works and where users clicked and scrolled, but they are not conclusive.

## Final Conclusion

Medsy focuses on the main journey a pharmacy user needs: finding the right medicine, understanding cheaper alternatives, verifying a prescription and tracking delivery. Clear delivery times, stock status and a side-by-side comparison of generic medicines help users decide with confidence.

Usability testing with Microsoft Clarity showed that real behaviour can be studied easily with one tracking script. The click, scroll and attention heatmaps showed that users mostly used the side menu and the Search Medicines button, and that attention was highest around the Quick Access and Monthly Medicines sections. Session recordings let us see how visitors moved through the pages.

Our design review also found points to improve: the main button colour is not consistent (blue and green), the delivery fee appears only at checkout, and the Place Order button stays disabled until a prescription is verified. We would fix these in the next version and test again with more users.
